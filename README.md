# Price Action Engine

This repository contains a TradingView Pine Script indicator for live session price action analysis.

## Included features
- Fair Value Gap (FVG)
- Change of Character (CHoCH)
- Break of Structure (BOS)
- Higher High / Lower Low detection
- Volume bubble markers

## File
- `PriceActionEngine.pine`

## How to use
1. Open TradingView.
2. Open the Pine Editor.
3. Paste the script from `PriceActionEngine.pine`.
4. Save the script and add it to your chart.

## Notes
- Best for intraday charts like 1m, 5m, and 15m.
- Adjust the pivot and volume inputs to reduce noisy signals.
- This is intended for educational and chart-analysis use.
